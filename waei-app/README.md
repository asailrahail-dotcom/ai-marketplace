# وعي (Waei)

تطبيق ديني هادئ (Expo / React Native) يساعد المستخدم على أن يصبح أكثر وعيًا
بالله، وبالنعم في حياته، عبر لحظات إيمانية قصيرة يوميًا. عربي بالكامل، RTL،
ويدعم الوضعين الفاتح والداكن.

## التشغيل محليًا

```bash
npm install
npm run web      # معاينة في المتصفح (react-native-web)
npm run ios      # يتطلب macOS / Simulator
npm run android  # يتطلب Android Studio / محاكي أو جهاز
```

لا يحتاج التطبيق إلى أي متغيرات بيئة أو مفاتيح API — كل البيانات تُحفظ محليًا
عبر `AsyncStorage`، ولا يوجد اتصال بأي خادم خلفي في هذه النسخة التجريبية.

## البنية

- `app/` — شاشات التطبيق عبر `expo-router` (توزيع بالملفات).
  - `index.tsx` — شاشة البداية (Splash) وإعادة التوجيه للإعداد الأولي أو للرئيسية.
  - `onboarding/` — ثلاث شاشات تعريف أولى بالتطبيق.
  - `(tabs)/` — التنقل السفلي: الرئيسية، الخلوة، مذكراتي، الإعدادات.
  - `content/` — نوافذ منبثقة (Modals) لكل من: آية اليوم، نعمة اليوم، سؤال
    اليوم، لحظة مع الله، أثر اليوم.
- `lib/` — الحالة العامة والتخزين والمحتوى: `app-state.tsx` (السمات، حجم
  الخط، الإشعارات، الإعداد الأولي)، `content.ts` (بيانات اليوم)،
  `notifications.ts`، `storage.ts`، `theme.ts`، `rtl.ts`.
- `components/` — عناصر واجهة مشتركة (بطاقات، أزرار، نص متكيف مع السمة...).
- `index.js` — نقطة الدخول المخصّصة: تفرض اتجاه RTL قبل تسجيل التطبيق (لازم
  لأن `I18nManager` على الويب لا يفعل شيئًا إلا إذا ضبطنا `dir` على مستند
  الصفحة يدويًا، أما على iOS/Android فتُستخدم آلية RTL الأصلية).

## ملاحظة حول المحتوى الديني

الآيات القرآنية المستخدمة (في `lib/content.ts`) مجموعة صغيرة من آيات قصيرة
ومعروفة، موثّقة باسم السورة ورقم الآية، لأغراض هذه النسخة التجريبية فقط.
قبل أي إطلاق فعلي يجب استبدالها بمصدر قرآني موثوق (مثل واجهة برمجية
معتمدة) بدل الاعتماد على هذه المجموعة اليدوية. خواطر التدبر المرافقة هي
تعليقات من إعداد التطبيق وليست تفسيرًا رسميًا، وتُعرض دائمًا بشكل منفصل عن
نص الآية.

## حالة الإشعارات

الإشعارات المحلية (`expo-notifications`) تعمل على iOS و Android فقط. على
الويب يتم حفظ تفضيل المستخدم دون جدولة إشعار فعلي (محدودية معروفة في بيئة
الويب لا علاقة لها بمنطق التطبيق).
